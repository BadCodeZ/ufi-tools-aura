# AURA v2.5.4 更新说明

> 基线 v2.5.3 / BUILD 1117b → **v2.5.4 / BUILD 1127a**

## 一、新增功能

### 1. 设备持久化壁纸

- 支持本机图片上传、远程图片网址与开关。
- 图片在浏览器端自动压缩为 JPEG，经设备官方上传接口保存到设备固定文件。
- 配置保存在 `/data/kano_cron/aura_wallpaper.json`，换浏览器或清理浏览器缓存后仍可读取。
- 支持浅色 / 深色主题独立遮罩强度；滑块实时生效。
- 外部图片仅允许 HTTP / HTTPS，设备上传图片仅允许同源 `/api/uploads/` 路径。
- 配置写入后执行 base64 回读校验，避免写入失败仍提示成功。
- 恢复默认只关闭背景并重置遮罩，不再删除已上传图片。
- 退出插件后不会继续读取或请求壁纸资源。

### 2. 设置页三项新增能力

- **语言 / Language**：沿用原有分段控件切换中英文。
- **告警推送**：统一为推送开关、推送通道、通道参数三个分组；保存时检查设备 `SAVED` 标记，设备名限制为安全短字符。
- **AURA 壁纸**：与原有设置页使用相同的分组、字段、主次按钮和状态说明。
- 三项设置统一移动到「关于设置」之前。

## 二、视觉与交互优化

- 建立壁纸态透明层级：侧栏、外层卡片、内部组件、普通控件、导航选中态分别使用固定档位。
- 概览顶部状态块、实时速率与四张主卡统一为同级材质，消除同页卡片两种层级。
- 移除标题与侧栏分组标题的矩形 `backdrop-filter`，修复透明按钮滤镜裁切形成的方形层。
- 降低整体模糊：侧栏 10px、外层卡片 6px、内部组件与控件 4px。
- 保持无壁纸状态完全回到 v2.5.3 主题，不影响原有布局和操作。

## 三、代码质量优化

- 删除旧壁纸渐变遗留变量与运行时写入。
- 合并新增设置主次按钮规则，避免重复覆盖。
- 清理未使用的常量与局部变量。
- 更新旧版本注释与专项测试版本断言。
- 壁纸设备专项纳入常规真机门禁。
- 修复设置卡片顺序变化后未同步的断言。

## 四、验证与体积

- 本地全量相关门禁通过：结构、安全、命令转义、输入转义、重复代码、体积、可复现构建、源码与压缩包行为一致。
- 关键真机回归通过：概览布局、中英文、停用后零请求、壁纸设备专项。
- 壁纸专项通过：旧存储清理、上传落盘、图片 HTTP 200、跨浏览器读取、遮罩实时生效、恢复默认保留图片、URL 白名单。
- 源码：**1,408,068 B**
- 压缩产物：**860,443 B**
- 压缩率：**61.11%**
- 距 1,420,000 B 管理线：**11,932 B**

## 五、已知环境限制

- 部分真机设置项依赖设备已存在的趋势、过滤器订阅和日志数据；数据为空时对应展示断言失败，与本次改动无关。
- 无头 Edge 偶发 CDP 启动超时；失败项单独重跑验证，不作为代码缺陷处理。
